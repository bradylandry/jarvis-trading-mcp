## Medium

### Token cache has no expiry or rotation-triggered invalidation
- **File**: `friend_mcp/server.py:73`
- **Issue**: `_token_cache` is populated once at startup and never cleared. If the Key Vault secret is rotated (a normal operational event), the server will continue using the stale token until a 401 is returned — at which point `_api_get` raises `RuntimeError` with no recovery path. The cache is never invalidated on failure, so every subsequent call also fails until the process is restarted.
- **Fix**: On a 401 response from the backend (`server.py:138-139`), clear `_token_cache` and retry once. A TTL-based expiry (e.g., 24h) would also guard against stale tokens silently persisting across key rotations.

### Rate limiter is not safe across multiple processes / replicas
- **File**: `friend_mcp/server.py:107`
- **Issue**: The sliding-window rate limiter uses `threading.Lock()` and a process-local `deque`. This is correctly thread-safe within one process, but provides zero protection if the Container App is ever scaled beyond `--min-replicas 1 --max-replicas 1` (set in `deploy.sh:39`). Multiple replicas would each enforce 30 req/min independently, allowing up to `30 × N` calls through to the upstream API. The deployment constraint is the only guard, and it lives outside the application code.
- **Fix**: Document the single-replica requirement prominently in the docstring and in README. If future scaling is anticipated, back the rate limiter with a Redis or Azure Cache counter keyed on the client identity.

### deploy.sh Key Vault hostname extraction is fragile and silently fails
- **File**: `deploy.sh:52`
- **Issue**: The script extracts the Key Vault name from `KV_URL` with `"${KV_URL#https://}"`. For a URL like `https://kv-jarvis-lab2.vault.azure.net/`, this yields `kv-jarvis-lab2.vault.azure.net/` (trailing slash included). The `az keyvault set-policy --name` argument with a trailing slash or a full hostname instead of just the vault name may fail, depending on the CLI version. The `|| echo "NOTE: grant ..."` swallows the failure silently.
- **Fix**: Use `--name` with just the vault short-name, not the full hostname: extract with `basename "${KV_URL%.vault.azure.net*}" | sed 's|https://||'`, or better, maintain a separate `KV_NAME` variable alongside `KV_URL`.
